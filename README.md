# Simple Interest Calculator

A simple interest calculator written in Bash script.

## Description

This repository contains a Bash script that calculates simple interest based on user input. The calculator takes three inputs:
- Principal amount
- Rate of interest
- Time period (in years)

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

```bash
bash simple-interest.sh
```

The script will prompt you to enter:
1. Principal amount
2. Rate of interest (in percentage)
3. Time period (in years)

The script will then calculate and display the simple interest.

## Example

```
Enter the principal amount: 1000
Enter the rate of interest: 5
Enter the time period (in years): 2
Simple Interest = 100
```
